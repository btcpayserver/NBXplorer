# NBXplorer.Client

`NBXplorer.Client` is the official .NET client for the [NBXplorer](https://github.com/btcpayserver/NBXplorer) REST API.

Install it from NuGet:

```bash
dotnet add package NBXplorer.Client
```

The client supports wallet tracking, unused address generation, balances, UTXOs, transactions, events, groups, rescans, PSBT creation, and transaction broadcasting.

See the [API integrator guide](https://github.com/btcpayserver/NBXplorer/blob/master/docs/API.md) for NBXplorer concepts and authentication, the [REST API reference](https://btcpayserver.github.io/NBXplorer/) for endpoint details, and the [multisig example](https://github.com/btcpayserver/NBXplorer/blob/master/Examples/MultiSig/Program.cs) for a complete client workflow.
